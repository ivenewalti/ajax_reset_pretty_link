### Halo, selamat datang

Repositori ini dibuat hanya untuk latihan *fork* — menyalin proyek orang lain ke akun sendiri.

Sebuah *fork* adalah salinan pribadi dari proyek milik orang lain. Ibarat jembatan antara repo asal dan salinanmu: kamu bebas mengubah apa saja di salinan itu, dan kalau perubahannya berguna, kirimkan kembali sebagai *Pull Request* supaya pemilik asli bisa mempertimbangkannya. Di situlah inti dari kerja kolaboratif di platform ini.

Setelah repo ini di-fork, silakan ubah satu-dua berkas lalu ajukan *Pull Request* sebagai latihan.

Panduan langkah demi langkah untuk proses fork tersedia di dokumentasi resmi platform. Selamat mencoba!
